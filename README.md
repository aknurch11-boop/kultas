# KülTas — биржа золы ТЭЦ

🌐 **Сайт: https://kultas.onrender.com** · демо-трекинг: https://kultas.onrender.com/track.html?code=KT-1001

**Из пепла — в бетон.** KülTas соединяет ТЭЦ, у которых копится зола, с бетонными заводами, производителями блоков и дорожниками. Каждая партия получает цифровой паспорт качества, а доставку можно отслеживать на карте в реальном времени.

> В августе 2026 года Казахстан впервые купил золу-унос в России для бетона (ТАСС/Fomag). При этом в казахстанских золоотвалах накоплено больше 300 млн т своей золы (КарТУ).

Языки сайта: **қазақша / русский / English**. Язык можно задать ссылкой: `?lang=kk`, `?lang=ru`, `?lang=en`.

## Как устроено (для вопросов жюри)

```
Браузер (public/)                                   Сервер (server.js, Express)
  home.js ──GET /api/batches, /api/stats, /api/config──▶ lib/store.js → data/kultas.json
          ──POST /api/orders────────────────────────────▶ lib/route.js → маршрут OSRM
  track.js ─GET /api/orders/:code (маршрут + время)─────▶ этап поездки считает public/js/trip.js
  dashboard.js ─POST /api/batches, GET /api/orders──────▶   (этот файл общий для сервера и браузера)
  passport.js ─GET /api/batches/:id
```

- **Фронтенд:** HTML, CSS и JavaScript без фреймворков. Карта Leaflet + OpenStreetMap, QR-коды через qrcodejs. Шрифты Noto Serif Display (с казахскими буквами) и Inter.
- **Бэкенд:** Node.js 20+ и Express 5, REST API, хранение в JSON-файле.
- **Трекинг:** сервер хранит расписание поездки, а браузер по нему двигает машину вдоль маршрута. Это работает без постоянных запросов к серверу, и все устройства видят машину в одной и той же точке.

## Деплой на Render (бесплатно)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/aknurch11-boop/kultas)

Нажмите кнопку → войдите через GitHub → **Deploy Blueprint**. Настройки уже лежат в `render.yaml`: Node, `npm install`, `npm start`, тариф Free.

Переменные окружения (все необязательны). Значения по умолчанию — **предположения команды**:

| Переменная | По умолчанию | Откуда |
|---|---|---|
| `CEMENT_PRICE_KZT` | 44000 | ≈2 200 ₸ за мешок 50 кг (OLX, Астана, июль 2026), пересчёт |
| `CO2_PER_TON` | 0.7 | диапазон 0,67 (Индия, CII) – 0,81 (Eagle Materials) т CO₂ на т цемента |
| `COMMISSION_PER_TON_KZT` | 2000 | предположение |
| `TRUCK_CAPACITY_T` | 25 | предположение |
| `REPLACEMENT_PCT` | 20 | ≈20% экономии цемента в дорожном строительстве Алматы (Forbes.kz) |
| `DEMO_TRIP_SECONDS` | 150 | длительность поездки в демо-режиме |

На бесплатном Render диск временный. После перезапуска заказы стираются, а демо-партии создаются заново.

## Честные ограничения

- Партии, лабораторные анализы, цены, водители и номера машин — **демо-данные**, они так и помечены на сайте. Координаты станций взяты из OpenStreetMap.
- Трекинг в демо **ускорен**. В реальной версии координаты будут приходить от GPS-трекера машины.
- Почему заводы покупают золу в России, а не берут местную, — **наша гипотеза**: не хватает подтверждённого качества и логистики. Её нужно проверить интервью с заводами.
- Юридический статус золы (отход или вторичное сырьё) нужно прорабатывать: Экологический кодекс и Кодекс о недрах противоречат друг другу.
- Казахский перевод стоит вычитать носителю языка.
